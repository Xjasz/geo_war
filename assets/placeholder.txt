This directory contains game sprites and assets.

The game will use colored rectangles as placeholder sprites if the actual image files are not found.

To add your own sprites, place PNG files in this directory with the following names:
- knight.png
- archer.png
- mage.png
- zombie.png
- skeleton.png
- vampire.png
- bat.png
- ghost.png
- health_potion.png
